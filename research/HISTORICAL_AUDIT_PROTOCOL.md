# Historical proposal audit: bounded post-hoc protocol

This is an explicitly post-hoc descriptive bridge between already collected model price proposals and a later mathematical action contract. It does not run models, make API requests, simulate protected counterfactual trajectories, or establish contract efficacy. The original 342 model decisions consumed the user's included allowance earlier; this audit adds zero model decisions.

Before calculation, run `node research/audit-historical-proposals.js --freeze`. It records this protocol, audit source, contract/economy source, and all selected input hashes. Then `--audit` must verify every hash before computing results. Frozen input membership is checked, including newly added files. Outputs contain no account metadata, thread IDs, raw prompts, or strategy-note text.

Include exactly six existing formation/study folders listed in audit source. Exclude both fixed-checkpoint probes (72 decisions). Expected included population: 270 individual decisions, corresponding to 135 simultaneous settlements across seven base formation episodes and twelve dependent continuation branches. These are not independent observations. Report discrepancies and fail closed on malformed actions, duplicate scope keys, or unexpected totals.

For each decision, use its exact last visible `observation.history` competitor price as reference. Never substitute hidden global history or actual current rival price. Empty history is retained as not auditable due to missing reference, and excluded from contract comparisons. Compare saved price against the calibrated best response and epsilon-profit interval, at epsilon `[0,0.01,0.1,1,8]`. Record lagged-reference own profit, optimal profit, regret, projected price, absolute projection distance, and would-adjust indicator (distance greater than `1e-9`). This evaluates today's frozen contract code, not an independently implemented validator.

Classify model from original decision, demand disclosure from original system text (manifest must agree), origin instruction from original manifest, and current receiver instruction from original system. Do not label a neutral replacement receiver instructed merely because its predecessor was instructed. Scope identifies formation/continuation and handover arm. Replace original seed identity with deterministic anonymous episode IDs; retain formation versus branch identity to expose dependence. Do not parse or publish note contents. Current-rival realized regret is intentionally omitted because this audit does not reconstruct settlement alignment.

Produce sanitized decision/epsilon CSV, sanitized decision summary JSON, stratified descriptive counts and averages by model, demand disclosure, origin instruction, current receiver instruction, and stage/arm. No significance tests, confidence intervals, semantic note claims, deliberate-collusion claims, safety claims, or counterfactual effects. Missing-reference counts remain explicit. A projection that would change an observed quote says nothing about how either model would behave afterward.
