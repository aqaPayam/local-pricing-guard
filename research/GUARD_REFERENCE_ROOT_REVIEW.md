This note grants no new numerical GO.

The strongest limitation of the existing learning evidence is that the guard
constrains each learner's legal choices. Successful enforcement inside those
constraints does not show that the learner could reach economically different
behavior without them. The new reference directly tests this limitation with
one new support rule, the same original bounded physical game and initial cap,
the same dense clock/memory representation, the same streams, initialization
and budget. Its value is a better controlled interpretation, not a new learning
algorithm or a claim of first invention.

The registered contrast is appropriate for the total change in training and
frozen continuation together. It cannot identify whether any difference arose
through learning, evaluation constraints or their interaction. The initial cap,
finite price domain, discrete memory and finite training budget also remain.
Neither a high-price outcome nor high joint profit alone establishes collusion.
An uninformative result must be reported as such without extending the budget
or substituting favorable seeds after inspection.

The legal action count intentionally differs even though dense memory and
rounds match. Full-grid exploration can therefore dilute visits per action.
This is part of the support-removal treatment, but equal budgets should not be
described as equal competence or equal learning difficulty. A low-price or
unstable full-grid result may leave broader capability unresolved.

The mathematical anchor design is sound: both WORLD-oriented best-response
sets, every pure Nash pair and every exact joint-profit maximum are retained.
Independent exact addition avoids a false tied objective from rounded A+B.
Static anchors add useful economic context but cannot certify a learned dynamic
equilibrium. Direct prices/profits/customer benefit are preferable to a selected
anchor-based index. Primary Python and separately authored JavaScript fixtures
already agree; actual market anchors have not been computed.

The new primary adapter retains the original physical record while replacing
phase1..4 supports. The independent adapter instead constructs a cloned
effective full-support view around the separately authored immutable replay
kernel. That difference is useful protection against sharing one mistaken
support implementation. Both explicitly declare the support treatment and
disable inherited guard floors. Artificial cross-author tests cover complete
dense arrays, transcript blocks, windows, graphs and asymmetric B orientation.
The old guard-specific parent validator must not silently approve new data.

replay and whole-inventory acceptance, treatment-aware parent validation,

root GO after both V12 deliveries close. Required endpoint failures remain
