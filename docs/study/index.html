NEW: TESTING THE BOUNDARY

One allowed price is not universal.

We changed the market, the number of available prices and the guard's tolerance. Some settings leave one allowed price; others leave several. A guard-aware seller scores 100% acceptance in both cases.

Eight configurations, eight paired training seeds each. Four numerical calibrations cover three distinct demand shapes; two calibrations differ only in units. Each seller trains for three million rounds. The tests below run for the same 20,000 rounds.

Acceptance counts unchanged proposals. Allowed count and range describe permission. Customer benefit and both profits describe economic outcomes. Comparing acceptance across different interfaces does not establish a better controller.

The guard-aware learner chooses and learns only among allowed prices. The naive executed-credit variant changes the rewarded Q-table cell but still considers forbidden choices, so it is a diagnostic, not a recommended algorithm.

Customer benefit is model consumer surplus. Feasible prices count distinct available executed actions, not proposals. All values average 12 independently seeded runs within one economic calibration; seeds are paired across variants.

Each release test begins from the identical trained checkpoint. High welfare while a guard is active does not establish that unconstrained behavior is safe afterward.

What this evidence supports

A controller must be compared with simple alternatives, and proposal retention must be read beside actual feasible choice, customer benefit and seller profit. A change to a display metric alone cannot establish more economic freedom.

These are local tabular learners in symmetric toy logit economies. High prices are not proof of deliberate collusion. The studies do not test language understanding, real markets or human comprehension. Action projection and action masking are established methods; our contribution is this matched economic comparison and its measured limits.
