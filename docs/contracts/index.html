A CONDITIONAL, ANALYTICALLY DERIVED RESULT

Recovery from arbitrary proposals—with a strict contract.

Requires the exact demand model, both shops protected continuously, authenticated previous prices, and simultaneous settlement. It concerns ideal mathematical constraints; floating-point implementation is audited separately. The profit tolerance is only about 0.0224% of Nash per-shop profit, so little price freedom remains.

“Half the harm” means half the gap between the Nash and joint-monopoly reference customer-benefit values. It does not mean half any actual initial harm. Six is a sufficient bound, not a necessary recovery time.

ALGORITHMS AND MATHEMATICS

1. Compute an allowed interval

Given the last rival price, use the public demand model to find the best profit. Allow a price only if its modeled profit loss is at most epsilon. Bisection finds the interval endpoints.

2. Project the proposed price

Keep a proposal inside the interval; otherwise clip it to the nearest endpoint. At epsilon zero the interval contains one price: classical best response, with no price-setting autonomy.

3. Bound the resulting dynamics

For this calibrated economy, the best-response map contracts price errors by a factor below one half. Positive tolerance adds a bounded error term under the stated bootstrap condition.

profit_i = (price_i − 1) × logit_demand_i
allowed(q) = {p : best_profit(q) − profit(p,q) ≤ epsilon}
executed_price = clip(proposal, lower_allowed(q), upper_allowed(q))
exact bilateral price error: e_t ≤ (1/2)^t e_0

More freedom can permit the high-price path.

The symmetric constant-price acceptance condition is a standard epsilon-Nash condition. At the joint-profit price, its threshold is about 7.420439 per-round profit units. A tolerance of 8 admits the high-price proposals unchanged even with permanent bilateral protection.

This is a pointwise condition on constant symmetric prices, not a global worst-case guarantee over all adaptive histories.

What the reviewers accept—and what they do not.

Accepted: the limited result

The conditional derivation, six-round corollary, implementation audit, and unilateral/release/model-error counterexamples. This is more than a selected scripted outcome because the mathematical claim covers arbitrary proposals.

Novelty: incremental

Logit demand, best responses, contraction, shielding and epsilon-Nash concepts are established. This is a specialized guarantee and failure map, not a new general anti-collusion algorithm.

Still missing

Protected learned-agent experiments, language-aware handover efficacy, uncertain-demand guarantees, and broader markets. No first-place forecast follows. No new Codex game-player calls were made.

Exploratory bridge to existing LLM quotes

The separate historical audit reuses quotes already generated before this stage. Of 270 quotes, 267 have a visible previous rival price; three do not. At tolerance 0.1, the contract would change 186 of those 267 quotes at their original states. This measures intervention burden only—it does not show how protected agents or rivals would behave afterward.
